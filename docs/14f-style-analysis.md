## 1-A. 영상 1 부분 분석 (TopDvMd_77Q, "경제 한쌈" 시리즈)

자료: 사용자 제공 썸네일 이미지 1장, 제목 텍스트, YouTube 자동자막(타임스탬프 포함).
영상 화면은 보지 못했으므로 **컷 전환·화면 구성·자막 디자인·모션그래픽은 여전히 미확인.**

### 직접 확인 (자료에서 그대로 관찰)

**제목**
- 형식: `주체, 사건ㅣ주체, 사건ㅣ주체, 사건 등 4가지 🥬카테고리🥬`
- 4개 이슈 중 3개만 나열, 각 6~10자 내외의 "명사, 명사" 압축형. 구분자는 한글 자모 `ㅣ`.
- 시리즈명 "한쌈"과 연결되는 상추 이모지로 카테고리를 감쌈(시리즈 말장난을 이모지로 표현).

**썸네일 (16:9)**
- 이슈 4개 = 사진 패널 4개 콜라주. 패널 경계는 찢어진 종이 질감(흰 거친 테두리).
- 각 패널은 이슈를 상징하는 실물 사진(회사 로고/매장/제품/건물/인물 컷아웃). 인물 컷아웃은 패널 경계를 넘어 튀어나옴.
- 한 패널에 기사 헤드라인을 흰 박스·검은 글씨로 캡처해 얹음.
- 좌상단: 시리즈 로고(흰색 손글씨풍 + 작은 낙서 아이콘). 우상단: 채널 로고(보라 배경에 노란 글자, 기울임).
- 하단 1/3: 어두운 그라데이션 위 2줄 대형 카피. 1줄 흰색, 2줄 노란색. 굵은 고딕, 그림자.
- 카피는 제목을 반복하지 않고 **시청 이득(쉽게 요약)** 을 말함. 음슴체("~함")로 끝맺음.
- 색: 노랑 + 보라 포인트, 흰/검 텍스트. 사진 일부에 미세한 망점(도트) 질감.

**대본 구조 (자막 기준)**
- 인사·채널 소개 없이 첫 문장부터 첫 이슈 시작.
- 이슈 4개 연속, "다음 소식" 같은 전환 멘트 없이 다음 훅으로 바로 넘어감.
- 이슈당 길이(자막 타임스탬프 기준 근사): 약 3분 50초 / 3분 15초 / 3분 15초 / 2분 25초. 전체 약 12분 40초 내외.
- 이슈별 공통 뼈대:
  1. 훅: 날짜·장소·규모 숫자 또는 공감 질문, 반전형 질문, "기억하시나요?" 회상형 — 이슈마다 훅 유형을 바꿈
  2. 시그니처 멘트: "(시리즈명)이 핵심만 정리해 드릴게요" 계열 — 이슈 1~3에서 반복, 4에는 없음
  3. 원인/구조 설명: 단계별 흐름(A→B→C), 구체적 금액·비율·건수를 촘촘히 사용
  4. "그렇다면 왜 ~? 노림수는 단순했습니다" 같은 자문자답으로 핵심 동기 설명
  5. 상대측 입장/공식 반응(회사 성명, 정부 대책)
  6. 확장 맥락: 과거 유사 사례, 다른 업체의 유사 사례
  7. 마무리: 열린 질문 또는 "지켜봐야 할 것 같네요"로 판단 유보
- 설명 장치: 가상의 예시 숫자로 시뮬레이션(예: 집값·보증금·월세 → 월 이자·절감액 계산).
- 대중 반응을 인터넷 표현으로 짧게 인용.
- 출처 언급: 외신·언론 보도를 문장 안에서 직접 언급("~에 따르면").
- 어미: "~는데요", "~거죠", "~셈이죠", "~해요" 위주의 부드러운 해요/합니다 혼합체.
- 자막에 `[음악]` 표기가 여러 번 나옴 → 나레이션 중 배경음악이 깔리는 구간이 있음(음악의 성격은 미확인).

**나레이션 속도 (측정)**
- 이슈별 40초 안팎 구간 4곳 표본, 한글 음절 수 ÷ 시간(숫자 읽는 음절은 제외해 실제보다 약간 낮게 나옴):
  310 / 386 / 346 / 360 음절/분 → **평균 약 350음절/분**, 문장당 평균 약 5~8초.

## 1-B. 영상 2 부분 분석 (KqoRsxSqv-U, 단일 주제 해설형)

자료: 사용자 제공 썸네일 1장, 제목, 자동자막. 영상 화면은 보지 못함.

### 직접 확인

**제목**
- `지하 100m 땅속에서 어떻게 수평으로 길을 뚫을까? / 14F`
- 장소·숫자를 앞에 두고 "어떻게 ~할까?"로 끝나는 질문형. 끝에 ` / 채널명`을 붙임(영상 1에는 없음).

**썸네일 (16:9)**
- 콜라주가 아니라 이미지 한 장: 위쪽은 도시 도로와 스카이라인, 그 아래 땅을 잘라낸 단면에 케이블이 깔린 터널이 보이는 "단면도" 연출.
- 흙과 터널 경계가 입자가 흩어지는 효과로 이어짐 → 합성 또는 생성 이미지로 보임(추정).
- 우상단 채널 로고는 민트 배경에 보라 글자. 영상 1(보라 배경, 노란 글자)과 색 조합이 다름. 시리즈 로고는 없음.
- 하단 2줄 카피: 1줄 흰색 "장소+숫자", 2줄 민트색 질문. 바닥은 어두운 보라 그라데이션.
- 썸네일 카피(전선을 어떻게 까나)와 제목(어떻게 수평으로 뚫나)이 같은 질문을 다른 각도로 말함 → 제목과 썸네일이 겹치지 않음(영상 1과 같은 원칙).

**대본 구조 (전체 약 4분, 마지막 타임스탬프 3:45 기준 추정)**
1. 일상 훅: 매일 쓰는 물건 3개를 나열 → "이 전기는 어디서 오는 걸까요?"
2. "결론부터 말씀드리면"으로 답을 먼저 줌
3. 배경: 발전소 위치, 송전 구조
4. 문제: 도심에 송전 설비를 늘리기 어려움
5. 시청자가 떠올릴 법한 쉬운 해법("땅에 묻으면 되지 않나?")을 꺼낸 뒤 왜 어려운지 설명: 기존 공법의 소음·진동·교통·사고 위험
6. 그래도 멈출 수 없는 이유(경관 보전, AI 시대 전력 수요)
7. "그렇다면 ~해야 하는 걸까요?" → "다행히" → 해결책 TBM 등장
8. "말 그대로 ~라는 뜻" 정의 → 작동 원리 → 비교 수치(진동, 소음)
9. "만능은 아닙니다"로 한계 짚기
10. 특정 기관의 도입 연도·기술 발전 사례 나열
11. 활용 분야 확대 전망
12. 감성 마무리: 보이지 않는 곳의 사람들 → 시청자가 다음에 떠올릴 장면 제시
- 어미: "~다고 해요", "~대요", "~다는데요" 같은 전언체가 매우 많음(정보를 들은 말처럼 전달).
- 반대 입장·비판은 없음. 특정 기관의 노력과 기술을 긍정적으로 마무리.
- `[음악]` 표기가 거의 매 문장마다 나옴 → 배경음악이 처음부터 끝까지 깔린 것으로 보임.

**나레이션 속도 (측정)**
- 표본 3구간: 336 / 360 / 351 음절/분 → **평균 약 350음절/분**, 문장당 약 5~6초. 영상 1과 거의 같음.

### 추정 (검증 필요)
- 특정 기관의 사업 소개와 긍정적 마무리, 반론 없음 → **협찬·브랜디드 콘텐츠일 가능성**. 설명란이나 영상의 "유료 광고 포함" 표시로 확인 필요.
- 썸네일 단면도 이미지는 AI 생성 또는 합성 이미지일 가능성.

## 1-D. 영상 3 부분 분석 ("지게차 자격증", URL 미제공)

### 직접 확인

**제목**
- `기능사 자격증 부문 1위… 너도나도 준비한다는 '지게차 자격증'? / 14F`

**썸네일**
- (참고: 일반인 얼굴은 흐림 처리 — 자체 제작 규칙 4-8에 반영)
- 사진 2장을 좌우로 합성: 왼쪽 시험장 대기 인파, 오른쪽 지게차 운전 현장. 가운데에 자격증 수첩 2개를 오려 붙여 두 사진을 이어줌.
- 오른쪽 사진 속 작업자 얼굴이 흐리게 보임 → 모자이크 처리로 보이나 저해상도라 확실하지 않음.
- 우상단 채널 로고: 민트 배경 + 보라 글자(영상 2와 같음).
- 하단 2줄 카피: 1줄 흰색 "주제 키워드", 2줄 민트색 "왜 이렇게 ~?" 질문. 바닥 어두운 그라데이션.

**대본 구조 (짧은 단일 주제)**
1. 공감 훅: "요즘 불안해서 자격증 생각하시는 분들 많으시죠?"
2. 유명인 사례로 관심 끌기 → 주제 공개("바로 ~인데요")
3. 공공기관 조사 결과로 순위 근거 제시(등급별 → 응시자 유형별 → 연령별로 좁혀가며 "1위" 반복 확인)
4. "그렇다면 왜?" → 이유 2가지(수요, 진입 장벽) → 기대 소득 숫자
5. 시험 정보(필기·실기 합격률)로 현실적인 난이도 제시
6. "흥미로운 점은" → 집단별 2~3위 비교
7. 의미 정리("~한 셈이죠") → 응시 이유 통계
8. 시청자 응원 멘트로 마무리("고생 많으십니다. 힘내세요. 파이팅!")
- 문장 약 25개, 한글 약 710음절. 숫자·통계가 거의 매 문장에 들어감.
- `[음악]` 표기가 자주 나옴 → 배경음악이 계속 깔린 것으로 보임.

### 추정 (검증 필요)
- 길이: 영상 1·2의 속도(약 350음절/분)를 적용하면 **약 2분~2분 20초**. 타임스탬프가 없어 실측은 못 함.
- 반론·비판 없이 정보 + 응원으로 끝나는 가벼운 생활정보형. 협찬 여부는 판단할 근거 없음.

### 영상 1·2와 비교해 새로 보이는 패턴
- 길이가 짧을수록 반론 단계가 빠지고, 마무리가 시청자 응원·공감으로 바뀜.
- 해설형 썸네일(영상 2·3)은 모두 `1줄 흰색 키워드 / 2줄 민트색 질문` + 민트 로고 → 해설형 공통 템플릿으로 보임(2개 사례 기반).
- 제목에 ` / 14F`가 붙은 것은 해설형 2개(영상 2·3), 붙지 않은 것은 시리즈물 1개(영상 1).

## 3. 분석에 필요한 파일

다음 중 하나라도 받으면 실제 분석이 가능함.

1. **영상 파일** (`.mp4`, 6개 각각) — 최우선. 컷 수·평균 컷 길이, 화면 구도, 색상 추출, 모션 유형을 프레임 단위로 측정.
2. **자막/스크립트** (`.srt` / `.vtt`, YouTube 자동자막 포함) — 분당 음절 수(나레이션 속도), 대본 구조, 문장 길이 측정.
3. **썸네일 이미지** (`.jpg`, 6개) — 레이아웃·글자 수·색 분석.
4. **제목·설명란 텍스트** (복사-붙여넣기 가능) — 제목 패턴, 설명란 구조.
5. 선택: 대표 장면 스크린샷 (영상당 5~10장) — 영상 전체 대신 쓸 경우.

전달 방법: 저장소 `refs/` 폴더에 업로드하거나, 대화에 첨부.
(대안: 이 세션에 연결된 Higgsfield 영상 분석 도구(video_analysis_create)가 YouTube URL을 받을 수 있을 수도 있으나 크레딧이 소모될 수 있어 실행하지 않음. 원하면 승인 후 시도 가능.)

## 4. 독자 콘텐츠용 제작 규칙 (초안 v0)

원칙: **기법(구조·리듬·정보 설계)만 차용하고, 14F/MBC의 로고·이름·캐릭터·진행자·대본 문장·음성·BGM·영상 클립·고유 그래픽은 쓰지 않는다.** 아래 수치는 출발값이며 실제 분석 후 조정.

### 4-1. 브랜드 분리
- 자체 채널명·로고·컬러 팔레트·폰트 조합을 새로 정한다. 원본과 혼동될 이름/층수 모티프("14F", "층") 금지.
- 진행자 외형·말투를 특정인 흉내로 만들지 않는다. 음성 복제 금지.

### 4-2. 화면 구성
- 세로(9:16) 우선 설계, 가로(16:9)는 재배치 버전.
- 세로 3분할: 상단 15% 고정 제목 / 중앙 55% 자료·진행자 / 하단 30% 자막 영역(플랫폼 UI와 겹치지 않게 하단 10%는 비움).
- 한 화면 정보 요소 최대 3개.

### 4-3. 색·글꼴
- 포인트 컬러 1개 + 보조 1개 + 무채색. 강조 단어만 포인트 컬러.
- 무료 상업 이용 가능 폰트 사용(예: Pretendard, 본고딕/Noto Sans KR). 제목 Bold/Black, 자막 Bold.
- 자막 1줄 최대 14자 내외(세로), 최대 2줄, 외곽선 또는 반투명 배경으로 대비 확보.

### 4-4. 대본 구조 (단일 이슈 60~180초 기준)
1. 훅 (0~5초): 질문 또는 의외의 숫자 한 개.
2. 맥락 (~20%): "무슨 일이냐면" — 배경 2~3문장.
3. 핵심 (~50%): 사실·숫자 3개 이내, 각 사실마다 시각 자료 1개.
4. 쟁점/반응 (~20%): 서로 다른 입장 최소 2개, 출처 명시.
5. 정리 (마지막 5~10초): 한 문장 요약 + 시청자에게 던지는 질문.
- 문장은 짧게(한 문장 한 정보). 구어체 허용, 비하·혐오·확인 안 된 단정 금지.
- 모든 사실 주장에 출처 기록(설명란 + 화면 하단 작은 출처 표기).

### 4-4a. 단일 주제 해설형 대본 — 영상 2 구조 기반 (약 4분)
1. 일상 훅: 시청자가 오늘 쓴 물건·행동 2~3개 → 그 뒤에 숨은 질문
2. "결론부터 말하면"으로 답을 짧게 먼저
3. 배경 → 문제 제기
4. 시청자가 떠올릴 쉬운 해법을 대신 말하고, 왜 안 되는지 설명
5. 그래도 해야 하는 이유
6. "그렇다면?" → 해결책 등장 → "말 그대로 ~라는 뜻" 정의 → 원리 → 비교 수치
7. "만능은 아니다"로 한계 짚기
8. 적용 사례·전망 → 시청자가 다음에 떠올릴 장면으로 마무리
- 전언체("~다고 해요")는 출처가 있는 정보에만 쓰고, 화면에 출처를 함께 표시.
- 협찬 콘텐츠라면 "유료 광고 포함" 표시를 하고 한계·반론을 최소 1개 넣는다.

### 4-4c. 짧은 생활정보형 대본 — 영상 3 구조 기반 (약 2분)
1. 공감 훅: 시청자의 요즘 고민을 질문으로
2. 사례 한 줄 → "바로 ~인데요"로 주제 공개
3. 공공 통계로 "1위/최다" 근거, 범위를 좁혀가며 2~3번 확인
4. "그렇다면 왜?" → 이유 2개 → 시청자에게 와닿는 숫자(소득, 비용, 시간)
5. 현실 체크(난이도, 조건)
6. "흥미로운 점은"으로 비교 포인트 하나
7. 한 줄 의미 정리 → 시청자 응원으로 마무리(자체 문구로)
- 유명인 이름은 공개 보도된 사실만, 출처와 함께. 초상 사진은 라이선스가 있는 것만 사용.

### 4-4b. 묶음형(여러 이슈) 대본 — 영상 1 구조 기반
- 인사 없이 첫 이슈 훅으로 시작. 이슈 사이 전환 멘트 없이 다음 훅으로 바로 넘어감.
- 이슈 3~4개, 이슈당 2분 30초~4분. 첫 이슈를 가장 길고 무게 있게.
- 이슈마다 훅 유형을 다르게: ① 규모 숫자 ② 반전 질문 ③ 시청자 공감 ④ 회상 질문.
- 자체 시그니처 멘트 1개를 만들어 훅 직후 반복 (원본 문구 사용 금지).
- 이슈 내부: 훅 → 시그니처 → 구조 설명(단계 흐름) → "그렇다면 왜?" 자문자답 → 상대 입장 → 유사 사례 → 열린 마무리.
- 제도·금융 이슈는 가상의 숫자 예시로 시청자 입장 손익을 계산해 보여줌.

### 4-5. 나레이션
- 기준값: 분당 약 350음절(영상 1·2 측정 평균이 모두 약 350), 허용 범위 310~390.
- 숫자·고유명사 앞에서 짧은 쉼으로 강조.

### 4-6. 컷 전환·편집 리듬
- 기본 하드컷, 문장/구 단위 점프컷. 평균 컷 길이 출발값 2~4초.
- 같은 화면 5초 이상 유지 시 줌·자료 삽입 등 변화 추가.
- 트랜지션 효과는 섹션 전환에만 1종류로 통일.
- 밈·인서트는 저작권 안전한 자체 제작/라이선스 소스만.

### 4-7. 모션그래픽 툴킷 (자체 템플릿으로 제작)
- 숫자 카운트업 카드, 막대/선 차트 1종, 타임라인, 지도 하이라이트, 키워드 팝업, 문서 하이라이트(원문 일부를 확대 + 형광펜 효과, 출처 표기).
- 등장 0.2~0.3초, 이징 통일, 동시에 움직이는 요소 2개 이하.

### 4-8. 제목·설명·썸네일
- 묶음형 제목: `주체, 사건ㅣ주체, 사건ㅣ주체, 사건 등 N가지 + 시리즈 이모지 카테고리` 구조 차용. 이모지는 자체 시리즈명과 연결되는 것으로 새로 정함.
- 해설형 제목: `구체 장소·숫자 + 어떻게/왜 ~할까?` 질문형, 또는 `순위·통계… 유행 표현 '핵심 키워드'?` 형. 썸네일 카피는 같은 질문을 다른 표현으로(제목 문구 그대로 반복 금지).
- 해설형 썸네일: 주제를 한 장면으로 보여주는 단면도·확대·비교 이미지 1장 + 하단 2줄 카피(1줄 흰색 장소·숫자, 2줄 강조색 질문).
- 강조색은 시리즈나 주제군별로 2~3세트를 정해 돌려 쓰되 원본 조합(보라+노랑, 민트+보라)은 피함.
- 일반인 얼굴이 식별되는 사진은 흐림 처리하거나 쓰지 않는다.
- 묶음형 썸네일: 이슈 수만큼 패널 콜라주 + 하단 2줄 카피(1줄 흰색 상황, 2줄 강조색 시청 이득). 패널 경계 효과·로고 배치·색 조합은 원본과 다르게 새로 디자인.
- 제목: 핵심 명사 앞쪽 배치, 30자 내외, 낚시성 과장 금지(본문이 답하지 않는 질문 금지).
- 썸네일: 큰 글씨 2~8자 + 대상 이미지 1개 + 포인트 컬러. 자체 촬영/라이선스 이미지만.
- 설명란: 3줄 요약 → 출처 목록 → 정정 안내 → 채널 링크/해시태그 3~5개.
